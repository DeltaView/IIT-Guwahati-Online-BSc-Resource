# DA-102 Data Analysis Basics

## Syllabus

Different forms of data (structured, unstructured, temporal and spatial) and their representation. Data files and their formats: csv, xlsx, text files, coded files, etc. Cleansing of data (missing values, duplicates, null values, data not in proper format, misplaced delimiter, embedded space characters or nonprinting characters, removal of unnecessary spaces), Data wrangling. Statistical analysis of data: tabulation, measure of central tendency (mean, median, mode), measure of dispersion and variance (range, variation, standard deviation), measure of skewness, time-series analysis using tools such as Excel and Spreadsheet. Data visualization for decision making: organizing and summarizing data using charts and graphs, PivotTables and Pivot Charts. Curve fitting and regression.
