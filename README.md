# IIT Guwahati Online BSc (H) in Data Science & AI Resources

This repository is a collection of resources for students enrolled in the **BSc (Hons) in Data Science & Artificial Intelligence** online degree programme offered by the **Indian Institute of Technology Guwahati (IIT Guwahati)**.

The goal of this repository is to make useful academic resources easier to find, organize, and share among students.

## What's Inside

Depending on the course and semester, you may find resources such as:

- Prescribed and Reference books
- Useful videos, links, articles, cheat sheets etc.
- Subject Notes
- Code examples etc
